GitHub Pages publishes the prebuilt `docs/` directory from `main`; `.nojekyll` preserves the reviewed output. The preview build changes only the site origin/base path and four corrected-PDF path references so links work beneath `/yalin-homepage-preview/`. Page content and styling match the accepted source. File hashes and preview path adjustments are recorded in `preview-provenance.json`.

The teacher's `master` branch and Pages configuration remain unchanged. Updating this preview requires a new reviewed build; it does not automatically follow future edits to the teacher branch.
